# Navigation icon generation

Generated with the built-in `image_gen` tool, with transparent backgrounds. The three PNG files live in `src/shared/assets/navigation/`, one per tool the navigation lists; these are 256 × 256 exports of the generated artwork, displayed at 44 CSS pixels. Alpha transparency is preserved. The full-resolution originals remain in the image generation output directory.

Motion Transfer was generated first. Its output was provided as a style reference for each of the remaining icons. These prompts are preserved verbatim for future additions to the set.

## motionTransfer

```text
Use case: stylized-concept.
Asset type: one production navigation icon for Open Photon, a dark AI filmmaking app. Square transparent PNG, isolated artwork, no background.
Primary request: design a beautifully clean, premium icon for MOTION TRANSFER: two simplified faceless human silhouettes in the SAME dynamic pose (one arm extended, one knee bent), with a single short curved arrow transferring motion from the left figure to the right. Exactly two figures and one arrow, unified compact composition.
Style: modern dimensional UI glyph, almost orthographic and front-facing, broad smooth solid shapes, gently rounded edges, very shallow bevels, satin ceramic finish. More restrained and graphic than a 3D toy. Bold legible silhouette at 40 pixels, no thin wire strokes, no small details.
Palette: pale lavender/ivory main figure (#d9ceff), medium violet secondary figure (#a68bff), one restrained magenta transfer arrow (#f072d8). Soft top-left lighting, clean edge separation on a near-black UI.
Composition: centered square, artwork occupies about 82 percent of the canvas, equal optical padding, no clipping. Actual alpha transparency outside the artwork.
Avoid: text, lettering, numbers, logos, watermarks, frames, app tiles, background gradients, checkerboard pattern, cast floor shadow, bloom, neon glow, particles, outlines, facial features, clothing detail, excessive gloss. This is a functional small menu icon, not an illustration scene.
```

## createCharacter

```text
Use case: stylized-concept.
Asset type: one production navigation icon for Open Photon, a dark AI filmmaking app. Square transparent PNG.
Input image 1 is a STYLE REFERENCE ONLY: match its softly beveled solid ceramic shapes, pale lavender/ivory, medium violet, restrained magenta accent, and soft top-left light. Create an entirely DIFFERENT subject described below; do not copy any people or arrows from the reference unless explicitly requested.
Style: beautifully clean premium dimensional UI glyph. Nearly front-facing orthographic view with very shallow depth. Simple broad smooth solid shapes, rounded edges, satin finish, bold silhouette, legible at 40 pixels. Keep the design restrained and graphic; prioritize recognition over detail.
Composition: a single compact centered symbol, artwork occupies about 82 percent of the square, equal optical padding, actual alpha transparency outside artwork.
Avoid: text, letters, numbers, logos, watermarks, external frames/app tiles, background gradients, checkerboard, floor shadows, bloom, particles, tiny details, fine outlines, excessive gloss.
Subject: CREATE CHARACTER. One simple pale lavender head-and-shoulders portrait bust with no face, paired with one bold small magenta four-point creation sparkle beside its upper-right edge. The bust is solid and gently sculpted; one simple violet shoulder layer gives depth. Exactly one portrait and one sparkle. No card/frame, no hands, no facial details.
```
